# macbootstrap 能解决哪些问题

下面列举使用 Mac 或开发过程中常见的一些痛点，以及 macbootstrap 对应的解决方式。可对照判断是否需要使用本套配置。

如有未被列出的痛点，欢迎[提交 issue](https://github.com/wmosys/macbootstrap/issues/new)，常见的共性问题会在后续版本中纳入。

## 环境与安装

1. 新 Mac 缺少包管理工具，或每次换机都要重新配置环境——一键脚本自动安装 Homebrew 并完成整套配置
2. Homebrew 官方源更新缓慢——已切换到中科大与清华镜像
3. 安装 Homebrew 后各类库仍需逐一手动安装——由 `install-steps/` 统一安装并建立配置软链
4. 想在终端科学上网或加速 npm 等命令——提供 `bssclient`（sslocal 客户端）与各语言镜像源配置

## 系统设置

5. 不了解如何用 `Tab` 切换系统对话框选项、用空格确认——开启完全键盘控制
6. 不了解如何配置三指拖动窗口——已开启三指拖动
7. 不了解如何把 F1-F12 作为标准功能键——已将 F1-F12 设为功能键
8. 不了解 QuickLook 可被扩展以预览更多类型文件——已安装一批 QuickLook 插件
9. 想隐藏菜单栏的 Siri、输入法等图标——通过预置 plist 配置

## 命令行效率

10. 还在用系统自带终端，不了解 iTerm2 的分屏与快捷键——已安装 iTerm2 并套用预置配置
11. 查找目录中的文件只能用 `find` 且不支持正则——`fn`、`bsfn` 支持正则查找
12. 想知道当前 IP 或公网 IP——`ip`、`myip`
13. 想让 curl、git 等终端命令走代理——`p on` 开启 / `p off` 关闭 / `p s` 查看状态与连通性（只影响当前 shell 会话）
14. 想查看磁盘剩余空间或目录大小——`bssize /`、`bssize .`
15. 只想看命令输出的前几行、后几行或指定行、指定列——全局别名 `H`、`T`、`R`、`C`
16. 想显示文件的绝对路径——`realpath`
17. 想忽略命令报错或丢弃输出——全局别名 `NE`、`NUL`
18. 习惯 Vim 键位，希望在终端管理文件——Ranger（`r` 启动，目录与外部 Shell 同步）

## Git 与开发

19. Git 还只会基本的 add / commit——大量封装见 [Git 指南](./git.md)
20. 想快速查看本地分支——`gb`
21. 记得某次提交信息或内容中的关键字，想找出该提交——`gg --grep`、`gg -G`
22. 每次调用 `ssh` 都要记端口、主机和密码——`ssh_config` 维护主机别名，配合 `ssh-copy-id` 免密登录
23. 想在终端格式化 JSON——`ppjson`
24. 想知道某进程占用哪些端口，或某端口被哪个进程占用——`bsof`
25. 需要 URL 编解码——`urlencode` / `urldecode`
26. 想在不打开 Xcode 的情况下快速打开工程——`ow`
27. 想在不打开 Finder 的情况下用 VSCode 打开目录——`c`

## 暂未覆盖

以下问题在历史版本中曾被提及，但当前仓库未提供对应实现：

- 邮件客户端的批量分类整理
- 剪贴板历史的关键字搜索
- 地址、手机号、身份证号、邮箱等常用片段的快速输入
- 浏览器效率插件的统一管理

如确有需要，可结合 Alfred、PopClip 等第三方工具补充。
